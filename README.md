# Elfera

## Local Car Kits E-Commerce Platform  
🔗 **Live Site:** *[elfaera.com](https://elfaera.com/)*  

### Inspiration 💡  
A local small business selling custom **car kits** needed a modern e-commerce platform that could support **mobile shoppers**, **international customers**, and **secure payments** without relying on expensive or inflexible third-party solutions. I built a **custom full-stack e-commerce website** tailored to the business’s needs, focusing on cost performance, scalability, and ease of product management.

---

### What it does 🔍  
Empowers the business owner to:  
- ✅ Sell products through secure Stripe-powered checkout  
- ✅ Collect customer emails and preferences to announce new product drops and send newsletters
- ✅ Apply discount codes and promotions  
- ✅ Offer automatic shipping options based on customer's shipping address  
- ✅ Manage products dynamically via a PostgreSQL-backed system
- ✅ Custom inquiry form allowing direct communication with the business owner  

Enables customers to:  
- 🛒 Browse and purchase car kits on mobile or desktop  
- 💳 Checkout securely with real-time price, tax, shipping, and currency updates  
- 🌍 Shop in their local currency (CAD/USD) with transparent pricing  

---

### How we built it 🦾  
**Tech Stack:**  
- **Frontend:** React, Redux  
- **Backend:** Node.js, Express.js  
- **Database:** PostgreSQL  
- **Payments:** Stripe API  
- **Design:** Mobile-first responsive UI  

#### Architecture & Workflow  

**Frontend:**  
- React with **Redux** for:  
  - Shopping cart and checkout state  
  - CAD/USD currency support  
  - Dynamic shipping options based on country  
  - Mobile-first UI optimized for conversion  

**Backend:**  
- RESTful Node/Express API  
- Stripe integration handling:  
  - Payments  
  - Discount codes  
  - Multi-currency pricing  

**Database:**  
- PostgreSQL schema enabling:  
  - Easy product creation and updates  
  - Scalable inventory management
  - Collection of customer preferences and email  

---

### Key Features ⚙️  
- 💳 **Stripe API Integration** (payments, discounts, multi-currency)  
- 🧠 **Redux State Management** (cart, checkout, currency, shipping)  
- 🌍 **Automatic Currency Switching** (CAD / USD)  
- 📦 **Dynamic Shipping Options** based on customer country  
- 📱 **Mobile-First Design** optimized for conversions  
- ⚙️ **PostgreSQL Product Management** for easy inventory updates  

---

### Challenges I ran into 🧠  
- Multi-currency consistency across cart, discounts, and checkout  
- Coordinating Stripe payments with discounts, shipping, and taxes  
- Managing complex checkout state cleanly with Redux  
- Ensuring shipping options updated dynamically without breaking UX
